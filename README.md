FIFA World Cup Dashboard Project

Objective-

To analyze FIFA World Cup data and build an interactive dashboard to uncover trends, patterns, and insights.

Dataset-

Dataset contains historical FIFA World Cup data including winners, goals, matches, and attendance.

Data Cleaning-

* Removed duplicates
* Handled missing values
* Standardized column names
* Converted data types
* Fixed inconsistent values

Dashboard Features-

* KPI Cards (Total Goals, Attendance, Tournaments)
* Winners Analysis
* Goals Trend Over Time
* Attendance Analysis
* Interactive Filters (Year, Country)

Key Insights-

* Brazil is the most successful team
* Goals scored have increased over time
* Attendance has grown significantly
* Certain countries dominate tournaments

Recommendations-

* Expand global participation
* Improve infrastructure in emerging regions
* Increase audience engagement strategies

Tools Used-

* Power BI
* Microsoft Excel
